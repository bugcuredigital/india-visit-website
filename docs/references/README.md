# Design references — full-resolution originals (gitignored)

The seven full-page PNG captures in this directory total roughly **90MB** and
are **deliberately not committed** (`.gitignore` excludes `docs/references/*.png`).
Putting that in the repository's history permanently, on every clone, is not a
reasonable cost for reference material that is not a build input.

**The committed, web-optimised versions live in
[`docs/design/references/`](../design/references/)** — ~400KB each, which is
ample for reading type scale, density and proportion. That directory's README
explains what these references are for and what must not be copied from them.

Keep the originals here in the working copy if you have them; re-encode the
derivatives from them whenever the set is re-captured.
